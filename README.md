# 螺旋丸实验室

基于希尔球涡的交互光线实验。独立目录、独立 Git 仓库，无服务器、无在线接口，无运行时跨项目依赖。

## 使用

直接打开 **螺旋丸实验室.html**。这是包含所有脚本与光带数据的单文件页面，可以离线打开、复制或分享。开发时也可直接打开 `index.html`。

五个入口依次为：内部翻卷、分层光丝、顶部螺旋、螺旋丸、球状闪电。已移除顶部“希尔球涡 / 希尔球”切换。默认打开横轴螺旋丸。

- 螺旋丸逐渐显影，最终使用视频开头的蓝色光丝、混合布点、横轴姿态与外围气流。采用相同流场，实时计算粒子运动。
- 球状闪电沿原有流线局部跳亮，逐渐增加折线、分叉及外围电流。两种动画共用球体，不另叠一个不相关的闪电球。
- 拖动停止自动转动；鼠标滚轮或双指缩放。空格暂停，方向键旋转，加减键缩放。
- 暂停同时冻结粒子、显影、电流和自动视角。重播恢复当前动画的相同起点。
- 手机顶部动画列表横向滑动；暂停、重播和缩放保持可达；详细参数通过“调整参数”展开。手机画布最多约 30 次刷新/秒，页面隐藏时停止计算。
- 遵循系统“减少动态效果”设置，此时等待手动播放。设备不支持浮点光照时退回轻量光线显示。

## 开发

```sh
npm ci
npm run build
npm test
```

构建先生成 `hero-renderer.js`，再将脚本内嵌到 `螺旋丸实验室.html`。运行页面不需要安装依赖。

- `physics.js`、`evolution.js`：独立复制的原始物理计算，公式未改
- `animations.js`：观看方式与确定的粒子起点
- `app.js`、`index.html`：交互、布局及轻量绘图
- `rendering/`：从视频开头复用的光照、流线与局部电流材质，改为适合交互画布的正方形显示
- `tests/`：物理守恒、流线、切换、重播、触控和离线产物检查

## 模型范围

经典球涡保留内部翻卷。附加旋流通过指定外力维持，光色不是温度或物质颜色。外围光带沿预设旋流路径运动；它是视频的艺术层，不把经典球外势流改成自发旋转。

球状闪电中的折线、分叉与发光是材质效果，没有求解放电或等离子体方程，不代表已确认球状闪电的成因。

原始实现来自 `physics/hill-vortex`，光照参考来自 `physics/hill-bubble-video`；必需源文件与数据均已复制进本仓库。原项目与已导出视频未修改。

## 小红书小工具

```sh
npm ci
npm run build:minitool
python3 scripts/package-minitool.py
```

产物为 `delivery/rasengan-lab-minitool.zip`，入口 `index.html` 位于压缩包根目录。全部资源离线加载，脚本外置并按 ES2017 / Chrome 61 目标构建。小工具的兼容样式和运行预算位于 `minitool/`，不会覆盖独立 HTML 的默认光效设置。

小工具默认最多 192 个示踪粒子、30 次刷新/秒；持续卡顿后逐级减少精细度、退回轻量绘图，再暂停运动。页面隐藏时取消刷新。WebGL 纹理默认 1024 方形，降级为 768 方形，限制绘制数量和画布分辨率。

指定的打包技能安装于本地 `.codex/minitool-zip-builder/`，未上传。安装后可审计：

```sh
python3 .codex/minitool-zip-builder/scripts/audit_artifact.py delivery/rasengan-lab-minitool.zip
```

包体和能力检查为静态检查；Chrome 61 浏览器、平台容器和手机性能尚未实测，不能据此宣称帧率达标。上传平台后需体验五个动画、拖动缩放、暂停重播、参数展开及切后台恢复。
